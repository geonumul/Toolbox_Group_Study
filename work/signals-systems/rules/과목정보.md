## 8. 수식 표기 (엔진이 KaTeX 로 그림)

- 본문 글 안의 수식은 `$...$`. 예: `$x(t-t_0)$`, `$e^{j\omega_0 t}$`, `$\delta[n]$`, `$u(t)$`, `$\sum_{k=-\infty}^{\infty} x[k]h[n-k]$`, `$\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\,d\tau$`.
- `formula` 의 `tex`, `parts[].sym` 은 `$` 없이 TeX 만.
- JSON 은 Python 생성 스크립트에서 raw string `r"..."` 로 쓴다(역슬래시). 수식 안에 한글이 필요하면 `\text{...}`.
- **엔진 버그 주의**: 수식 밖 글에서 공백 두 개 사이에 숫자만 있으면(`값은 3 이에요`, `n = 0 일 때`) 엔진이 그 숫자를 지워 버린다. 숫자는 `$n=0$` 처럼 수식으로 감싸거나, `3이에요`, `3칸`, `0에서` 처럼 붙여 쓴다. `check_sig.py` 가 잡는다.
- 허수 단위는 `j` (교수님, 교재 표기). 각주파수 `\omega`, 주기 `T_0`, `N_0`.
- 용어 표기: 나올 때마다 `**한국어(English)**`, 사전 `rules\용어사전.json` 의 ko, en 을 글자 그대로. 예: `**단위 임펄스(Unit Impulse)**`, `**LTI 시스템(Linear Time-Invariant System)**`(처음), 그 뒤 같은 쪽에서는 `**LTI 시스템(Linear Time-Invariant System)**` 을 반복하되 너무 길면 한 장면에 한 번. 사전에 없는 새 용어가 필요하면 glossary 에 추가하고(같은 형식), 최종 보고에 적는다.
