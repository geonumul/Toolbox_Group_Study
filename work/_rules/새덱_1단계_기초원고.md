# 새 덱 1단계: 기초 원고 (2026-10-11)

사용자가 새 강의 PDF 를 넣었다. 덱 하나에 도우미 하나. 이 단계에서 만드는 것은 **다른 모든 단계 (회독 레슨, 정리 슬라이드, 문제은행, 가리고 설명하기) 가 따르는 기준**이라 정확해야 한다.
먼저 읽을 것: `work\_rules\00_공통_원칙.md`, 맡은 과목의 `work\<과목>\rules\과목정보.md`.

## 입력
- 슬라이드 글자층: 시공실무 `work\interior-construction\_src\text_<N>.txt`, 근현대 `work\modern-space-design\_src\txt\<덱>.txt`
- 슬라이드 그림 (가로 1400px): `work\<과목>\_src\png\<덱>\pNNN.png`. **그림, 표, 사진 속 글자와 숫자는 글자층에 없다. 반드시 그림을 Read 로 열어 본다.**
- 같은 과목의 기존 덱 결과물을 본보기로: 용어 `terms\<주차>.json`, 정리노트 (시공 `_src\note_src_3.html`, 근현대 `pages\note.html` 의 s31~s35 절), 가리고 설명하기 소단원 `recall\<덱>_sections.json`, 암기 팁 `pages\tips.html`.

## 만드는 것 (맡은 덱 하나에 대해, 다른 덱의 파일은 건드리지 않는다)
1. **용어** `work\<과목>\terms\<주차>.json`: 기존 파일과 같은 형식 `[{"ko","en","say","more"}]`. 이 덱의 시험에 나올 용어 전부 (보통 40~70개).
   `ko` 는 슬라이드 표기 그대로 (한국어(English) 꼴이 슬라이드에 있으면 en 에 영어), `say` 는 처음 듣는 학생용 한 줄 뜻, `more` 는 숫자, 짝, 순서 같은 시험 포인트.
2. **정리노트 절** (원문 정리 + 쉬운 설명):
   - 시공: `work\interior-construction\_src\note_src_<주차>.html`. `note_src_3.html` 과 똑같은 구조 (`<h1 class="part">`, `<section id="sNN"><h2>`, 원문 정리 블록과 쉬운 설명 블록, 그림 자리 `{{fig:<주차>_pNNN}}` 는 쓰지 않는다 (그림 자르기 도구가 없다)).
   - 근현대: `work\modern-space-design\_src\note_add_<덱>.html` (조각 파일. 메인이 pages\note.html 뒤에 붙인다). `pages\note.html` 의 기존 절과 똑같은 마크업.
   - **절 번호는 아래 배정 범위 안에서 1부터 차례로**. 절 하나 = 슬라이드 쪽 범위 하나 = 정리 슬라이드 단원 하나 = 문제은행 unit 하나 = 가리고 설명하기 큰 묶음 하나.
3. **단원 목록** `work\<과목>\_src\units_<덱>.json`: `[{"sec": "s19", "id": "4-1", "title": "4-1 목재의 특성", "pages": [1, 12]}]`. 쪽 범위는 1쪽부터 끝 쪽까지 빈틈, 겹침 없이.
4. **가리고 설명하기 소단원** `work\<과목>\recall\<덱>_sections.json`: 기존 `<덱>_sections.json` 과 같은 형식 (큰 묶음 = 단원, 그 안 소단원마다 쪽 범위). 1쪽부터 끝 쪽까지 빈틈, 겹침 없이.
5. **암기 팁 조각** `work\<과목>\_src\tips_add_<덱>.html`: 기존 `pages\tips.html` 의 카드 마크업 (`<div class="card"><h3>...</h3>...`) 그대로, 이 덱의 헷갈리는 짝, 외울 숫자/연도, 순서 외우기, 목록형 서술 (논술) 답, 함정. 카드 2~5장.
6. **과목정보 조각** `work\<과목>\_src\info_add_<덱>.md`: 과목정보.md 의 덱 표 한 줄, 단원과 쪽 표, (시공) ★ 나 "출제" 표시가 붙은 쪽, 슬라이드 오타나 원본 오류 목록, 그림 속에만 있는 숫자 목록.

## 규칙
- 사실과 숫자, 이름, 연도는 **슬라이드에 있는 것만**. 슬라이드 밖 지식은 쓰지 않거나 "슬라이드 밖 내용" 이라고 밝힌다. 사진만 보고 알 수 없는 이름은 지어내지 않는다.
- 녹음, 기출이 없다. 교수님이 말했다고 쓰지 않는다.
- 금지 문자: em dash (U+2014), en dash (U+2013), 가운뎃점 (U+00B7), 불릿 가운뎃점 (U+2022). 슬라이드 원문에 많으니 옮길 때 쉼표, 하이픈, 괄호로 바꾼다. 붙어 나온 띄어쓰기는 고쳐 쓴다.
- 슬라이드 오타는 고치지 않고 info_add 에 적는다.

## 끝나면 확인 (스크립트 파일로)
- JSON 이 읽히고 형식이 기존 파일과 같다. 쪽 범위가 1~끝 쪽을 빈틈없이 덮는다. 절 번호가 배정 범위 안이다. units 와 note 절, sections 큰 묶음의 수와 이름이 맞는다.
- 금지 문자 없음.
